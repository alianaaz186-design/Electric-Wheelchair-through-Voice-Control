# 🦽 Innovative Wheelchair

An innovative assistive technology project designed to improve mobility, safety, and accessibility through electronic control and smart safety features.

## 📌 Project Overview

The project focuses on developing a smart wheelchair with electronic control and integrated safety features to provide a convenient and safer mobility solution.

## ⚙️ Key Features

- Electronic movement control
- Obstacle detection for safer navigation
- Emergency push button for immediate safety response
- Motor-based movement system
- User-friendly operation
- Practical assistive technology solution

## 🛠️ Technologies & Components

- Microcontroller
- DC Motors
- Motor Driver
- Obstacle Detection Sensor
- Emergency Push Button
- Battery / Power Supply
- Control Interface
- Wheelchair Mechanical Structure

## 🔧 Working

The user provides movement commands through the control interface. The microcontroller processes these commands and controls the motors through the motor driver.

The obstacle detection system monitors the path and detects obstacles during movement. An emergency push button is also provided to activate an immediate safety response when required.
